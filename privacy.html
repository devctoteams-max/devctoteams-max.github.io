This policy explains what the Devcto Studio app ("the app") does with information from TikTok and other platforms. The app is a desktop tool that runs on the creator's own computer.

Information the app receives

  • Login tokens issued by TikTok when you authorize the app. They are stored only in a configuration file on your own computer and are used only to call TikTok's API on your behalf.
  • Basic profile information (open ID, display name, username, avatar) and posting settings TikTok returns for your account (allowed privacy options, whether comments, duets and stitches are allowed, maximum video length). These are shown on the posting screen and are not stored.
  • Publishing results (publish ID, status, post ID), saved in a local text file next to the video so the same video is not posted twice.

What the app does not do

  • It does not run a server and does not send your data to the developer or to anyone other than TikTok.
  • It does not sell, rent or share your information, and it does not use it for advertising or analytics.
  • It does not read your videos, followers, messages or any other TikTok data beyond what is listed above.

Your choices and deleting data

You can revoke the app's access at any time in TikTok: Settings and privacy → Security and permissions → Apps and services permissions. To delete everything the app stored, remove the login token line from the configuration file and delete the local publishing-result files. Tokens also expire automatically if not used.

Children

The app is not intended for anyone under 18.

Changes

If this policy changes, the new version will be posted on this page with a new date.
